# Warehouse Keeper Voice v0.4.0

本版一件事：**可选的 AI 归一化（第 ② 步）**——本地匹配没听出物品名时，才把「识别出的那句话 +
本地前 8 名候选」交给一个小模型改写一次，再由**本地匹配器复判**；只有本地也认了才下单。
**默认关闭**：不打开开关、不填 Key，一个字节都不出网。音频、玩家名、坐标、仓库坐标、整份仓库
清单都**从不**发送。

## 🧩 新增：说得中「具体那一种」（配主体 1.2.1）

仓库里同名不同料的物品（迟缓药水 / 喷溅型迟缓药水 / 各种附魔书 / 不同飞行时间的烟花…）在快照里
每种各占一行。语音候选表现在按**变体键**建：说「迟缓药水」就取那一种，不会拿另一种药水顶包，
也不会再回「没听出物品名」；数量按该物品的**真实堆叠上限**折算（「半组迟缓药水」= 1 个，因为
药水一组就是 1 个）。下单时把变体键原样交给主体的 `warehouse order`，主体 `Porter.resolveEx`
第一步就认它。**需要主体 `warehouse-keeper` 1.2.1 或更高**；只装语音包（0.4.0 配 1.1.x）时
行为与以前一样。

## ✨ 新增：AI 归一化（可选，默认关）

- **什么时候才会联网**：一次「按住说话」里，本地匹配器**没把握**（没听出物品名，或名字只是相近、不像同一件东西）、并且开关是开着的，
  才会问一次；本地已经听懂了就直接下单，一个请求都不发。一次识别**最多问一次**，失败不重试
  （下一句再说），所以不会堆请求、不会卡住下一次录音（网络调用在识别 worker 线程里，超时
  默认 1000 ms，可配 500–3000）。
- **只发这两样**：① 语音识别出的文字；② 本地打分前 8 名的候选（物品 id、中文名、库存数）。
  **不发**：音频（音频从不落盘、识别完即清）、玩家名 / UUID、坐标、仓库坐标、整份仓库清单、
  聊天记录。
- **四个预设 + 自定义**（设置页点一下轮换，全部走 OpenAI 兼容 `/chat/completions`）：
- **候选排序会照顾「 · 」前的干净名字**：带属性的候选行名字里有注解（「迟缓药水 · 药水：迟缓 IV 0:20」），排序时同时比整行和干净名字，玩家只说「迟缓药水」也能把它排进前 8，模型再从里面挑具体那一行（`#N`）。

  | 服务 | 地址 | 默认模型 | 需要 Key |
  | --- | --- | --- | --- |
  | 智谱 BigModel（默认） | `https://open.bigmodel.cn/api/paas/v4` | `glm-4.7-flash` | 是 |
  | 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen3-8B` | 是 |
  | 本地 Ollama | `http://127.0.0.1:11434/v1` | `qwen3:0.6b` | **否**（完全离线，第一次调用会慢一点） |
  | 自定义 | 手填 `rewrite.url=` / `rewrite.model=` | — | 看服务 |

- **严格契约 + 本地复判**（这是「AI 出错最多是没帮上忙」的保证）：
  模型按件回行（每行 `item=…; amount=…; rewrite=…`，一句话最多 4 行）；每行 `item` 必须落在**本地前 8 名候选**里，
  `amount` 只认 `全部 / N个 / N组 / 半组`（含中文数字写法「一组」「两组」）；缺字段、多字段、
  单件句里夹换行、JSON、Markdown 包装一律作废（多件句按上面「每件一行」的写法，不是单行）。结果**不直接下单**：先拿改写后的句子跑一遍本地匹配器，
  本地不认就按「没听出物品名」处理；库存不足、单次上限 4096 这些既有安全阀**一个都不放宽**。
- **额度与省钱**：本地令牌桶 20 次/分、200 次/天（低于各家免费层）；归一化结果缓存 LRU 500 条；
  模型救回成功后把「这句话 → 物品 id」写进别名表，**同一说法第二次就不再联网**。设置页状态行
  显示「今天已用 N 次 · 上次 X ms · 结果」。
- **失败矩阵**：超时 / 连不上 / DNS 失败 → 记一条 debug 日志，退回本地提示（不崩、不卡）；
  HTTP 401 → 提示一次「Key 无效或未填」并**自动把开关置回 off**并落盘；HTTP 429 → 60 秒内不再调用；
  输出里没有 `item=`、`item=none`、`item` 不在候选里、`amount` 非法 → 一律当没答（**不会**退化成
  「只取 1 个」）。
- **界面**：`/warehousevoice` 新增「AI 归一化」分区 5 行（开关 / 服务 / 模型 / API Key / 状态）。
  主体面板「设置 → 语音取货 → AI 归一化」页里**可以直接填 / 改 / 清空 API Key**（真的输入框，
  回车或离开这一页才提交，只显示前 4 位），AI 地址与模型名也能在这一页改 —— 不必再跑一趟
  `/warehousevoice`；两边写的是同一份 `settings.txt`。老主体上这三行退成只读，提示去
  `/warehousevoice` 填。

## 📖 配置（`config/warehouse-keeper-voice/settings.txt`）

```
rewrite=on | off          是否启用 AI 归一化（默认 off）
rewrite.preset=           预设 id：zhipu / siliconflow / ollama / custom（默认 zhipu）
rewrite.url=              接口地址（留空时按预设）
rewrite.model=            模型名（留空时按预设）
rewrite.key=              API Key（默认空；本地 Ollama 不用填）
rewrite.timeout=1000      超时毫秒（500–3000）
```

- **Key 是本机明文保存**（和 `primary`、`mirror` 同一份文件，方便手改）：该文件在
  `config/warehouse-keeper-voice/`，不在存档里、不进 git。**不要把这个文件发给别人。**
- 手改 `settings.txt` 后重进游戏即可生效（和原有规矩一致）；界面上只能填 Key、换服务，地址与
  模型名走手改（预设之外的组合）。
- 老配置向后兼容：没有 `rewrite.*` 键就是「关」，行为与 0.3.0 完全一样。

## 🗣️ 听错了会提醒，但不会下错单（本轮新增）

- 名字说错但**拼音很像**时（例：「身板盐」→「深板岩」、「按山眼」→「安山岩」），聊天栏会回一句
  「没听出「身板盐」；是想说「深板岩」吗（同音 0.98）？」，
  **仍然不会下单**。
- 你 90 秒内改口说对、而且指的是同一件东西时，刚才那个错法会被记进
  `config/warehouse-keeper-voice/aliases.txt`，以后再说错也能直接命中（同一份文件，可手改、可删）。
- 门槛（音节相似度 ≥ 0.72、且领先第二名 ≥ 0.10）故意设得保守：**宁可少提示，也不乱猜**。
  难度太大的错法（如「按山眼」这类三音节里错一个的）仍然按「没听清」处理，不会瞎绑物品。
- **相近不等于同一件**（本轮新增）：名字只差一两个字、但读音差得远时（例：仓库里只有「橡木木板」，你说「橡木原木」），以前会被当成同一件直接下单 —— 现在只回「没找到「橡木原木」（可能仓库没有，或没听准）；最接近：橡木木板」，**不下单、不顶替**；开启 AI 时这句话还会交给 AI 复判一次，但模型点名的件必须在你的原话里找得到同源说法，否则一样不下单。

## 🧭 新增：分区标题 + 下拉选择 + 「测试连通性」（配主体 1.2.1）

- 设置页按功能**分区**：识别模型 / 识别方式 / 模型下载 / AI 功能（AI 页再分 服务凭据 / 连通性 / 用量），每区一行暗底亮字标题 + 一条细分隔线，不再把十几行堆成一列灰墙。
- 需要在多个值里挑的行改成**下拉菜单**：主模型、副模型、下载源、AI 服务。点开挑选、选中打 ✓、超过 8 项可滚轮、按 **Esc** 只收起下拉不关面板。
- AI 页新增「**测试连通性**」按钮：填完地址与 Key 想确认通不通，点一下即可 —— 状态行给出结果与延迟（`通 · 312 ms`；失败给 `Key 无效或没权限（HTTP 401）` / `超时（超过 1000 毫秒）` / `连不上：ConnectException`）。只发一个 ping，**不占额度、不写统计、不关开关**，跑在后台线程不卡游戏。

## 🧠 说得细也听得懂（配主体 1.2.1）

- **复杂要求也会问 AI**：句子带着等级/型号（例「要一本深海探索者3附魔书」）时，本地就算认得出也会问一次，让模型把详细说法改写成合法契约。
- **候选按「与这句话有多像」排序**：不再按仓库顺序截前 8 个（以前等于把仓库最前面的东西丢给模型）。
- **名字用服务端全名**：变体行不再只取 `·` 前那段，「附魔书」能区分成 `附魔书 · 深海探索者 III` 这一本。
- **等级写法等价**：服务端名字里的罗马数字（`III`）与嘴里的「3」按同一套写法比较；名字里的数字不再被当成数量切开。
- **智谱默认模型换成 `glm-4-flash-250414`**（实测比 `glm-4.7-flash` 快很多）；超时默认 1 秒 → **3 秒**，面板 AI 页多一个「**AI 超时**」下拉（1/2/3/5 秒）。

## 🧩 新增：一句话要好几件东西

- 说「给我一本背刺附魔书和一张绿色床」不再整句作废：先由**本地**按「和 / 还有 / 以及 / 、 / ，」等连接词拆句，每件单独认（数量词、别名、变体都照旧），**全对得上就直接逐件下单、不问 AI**。
- 本地有认不出的那件时才问 AI，AI 的回包改成**多行**（每件一行，最多 4 件）；每行仍要过本地匹配复判，AI 永远不会直接下单。补齐时**本地已认出的那几件不会丢**：本地的和 AI 补的按物品 id 合并后一起下单。补齐时**本地已认出的那几件不会丢**：本地的和 AI 补的按物品 id 合并后一起下单。
- 候选池按每件的说法打分取前 **8** 个；同一句里说到同一物品的两次会先合并数量。
- 超过 4 件会提示「一次最多说 4 件东西，请分开说」；一件都没听出时提示用「和／还有」把每件说清楚。

## 🎛️ 新增：三种用法（完全本地 / 两个一起 / 完全 AI）

用户 m42053（「在设置里加个下拉选项，选择完全使用本地规则或者完全调用AI改写或者两个一起」）：

- **完全使用本地规则**：一个字节都不出网（等同关掉 AI），但 Key 与服务配置保留。
- **两个一起（本地优先）**：默认，升级无感——本地先认，本地没把握才问一次 AI，AI 契约仍要本地复判。
- **完全调用 AI 改写**：每一句都先问一次 AI；AI 给出合法契约时优先采用；超时 / 没 Key / 契约不合法时
  退回本地结果并提示短原因（`AI 超时，用本地` / `AI 没填 Key，用本地`）。
- 入口：面板「设置 → 语音取货 → AI 归一化」页与 `/warehousevoice` 设置页的「方式：…（点一下换）」按钮；
  `settings.txt` 里是 `rewrite.mode=both|local|ai`（中文别名也认）。

## 🧩 新增：报错说清原因 + 带属性物品能选对

- **报错按原因说**：仓库里确实没有这件东西时，提示「没找到「橡木原木」（可能仓库没有，或没听准）；最接近：…」；连物品短语都没听出来时是「没听出「…」；最接近：…」。多件句逐件说清哪件没对上、为什么。
- **带属性物品能选对**：药水的时长/强化等级、附魔等级、烟花飞行时长这类「同一物品多个属性行」，AI 现在按候选表里的编号回答（`#1`、`#3`），并照抄整段变体 id；基础 id 对应多行时不会瞎猜，一律作废重来。本地复判也不再因为注解（「药水：迟缓 IV 0:20」）把正确变体拒掉。

## 🧹 回显更短 + 数量词更全（2026-10-17 追加）

- 成功回显缩成一行：`已取货 16 个橡木原木`；AI 帮上忙时行尾只留 `（AI）`，说对一次被记住时留
  `（记住了）`；几件东西是 `已取货：…、…`。不再追加「（服务器确认后会派假人）」与 AI 归一化长注解。
- 听得懂「X分之Y组」：四分之一组、八分之三组、三分之二组…按该物品真实堆叠上限折算
  （四分之一组 × 64 = 16）；「三组」「半组」也照旧。
- 失败提示保留原因（库存不够、没假人、仓库里没有…），只是不再重复「（服务器确认后会派假人）」「改口说一遍我就记住」这些长尾；诊断细节在 `logs/latest.log`。

## 🗣️ 口音也能认（2026-10-17 追加）

- 普通话不太标准、或者带一点口音时，识别常常会把字换成读音相近的别字：「石」→「四」、
  「蓝」→「南」、「深」→「森」、「熔」→「龙」、「黏」→「连」。现在比较前会先把**平翘舌
  （zh/ch/sh ↔ z/c/s）、n/l、r/l、f/h、前后鼻音（-ang/-an、-eng/-en、-ing/-in）**折叠掉再比，
  说「给我一组森板岩」也能认出深板岩。
- 折叠只用来**排序与提示**；「是不是同一件东西」仍要求折叠后读音完全一致，不会因为口音把
  橡木原木当成橡木木板（仓库只有木板时说「原木」照样不下单）。

## 🧸 名字只说一半也认得（2026-10-17 追加）

- 有的物品真名后面跟着组件注解（「不祥之瓶 · 凶兆等级 III」「药箭 · 药水：不祥之兆 III」），以前必须把
  整串说全才认；现在**整名、干净名、干净名 + 等级**三种写法都参与比较：说「不祥之兆3」也能落到
  「凶兆等级 III」那一行，说「药水箭」也能落到「药箭 · 药水：不祥之兆 III」。
- 句尾数字当**等级**用：说「不祥之兆3」下 1 个（不是 3 个）；仓库里只有别的等级时宁可说没找到，
  也不会拿「等级 I / II」的货顶替。
- 普通物品不受影响：说「石头3」里的 3 仍然按数量算（3 个石头）。

## 🔢 变体等级按数字说（2026-10-17 追加）

- 面板上的等级写的是罗马数字（`凶兆等级 IV`、`药水：迟缓 IV 0:20`），说的时候直接说数字：
  「不祥之兆4」= 凶兆等级 IV（IV=4、V=5 这样换算），下 1 个；「不祥之兆5」= V。
- 仓库里同名的两行只差注解时（例如两瓶迟缓药水 IV / I，玩家只说「迟缓药水」不带等级），
  不再随便挑一行下单，改回一句「仓库里有 2 种差不多的东西，说清楚是哪一种：…」，补一句等级再说即可。
- 说错等级（仓库没有那一档，例：只有 IV / V 时说「不祥之兆3」）照旧不下单，不拿别的等级顶替。

- **同一件东西的证据**（`VoiceMatchProbe`）：原木↔木板、铁剑↔金剑、石头↔石头台阶不算同一件；沙粒→沙砾、身板盐→深板岩、下季和金剑→下界合金剑、变体重排、短说法（不祥之兆3→凶兆等级 III、药水箭→药箭行）、真实仓库变体（不祥之兆4→IV、迟缓药水4→强化行、分不清时列出两种）算同一件，**64/64**。
- **发布 jar 契约探针**（`experiments/\voice-jar-probe\`）：直接对发布 / 安装的那只 jar 做二进制断言（常量、拆句、多行契约、tokenBudget、`plausible`/`mentions`、`#编号`选变体、口音折叠、真实变体等级选择），**56/56**，三份 jar 同 sha256。
- **游戏内实测清单**（需要真人做，见下）：真 Key 与真服务商的联调不在自动化范围内。

## ✅ 建议的实机检查

1. 开关关着说「给我半组圆石」→ 应取 32 个（不联网）。
2. 开开关 + 填 Key，说一句本地一定听不懂的（例：「下季和金剑来一把」）→ 看聊天栏有没有 AI
   改写的回显、是否取对。
3. 断网说同一句 → 退回本地提示，不卡不崩。
4. 故意把 Key 改错 → 提示一次并自动把开关置回 off。
5. 同一句说两遍 → 状态行次数只加一次（缓存 / 别名生效）。
6. 看 `logs/latest.log`：识别耗时不应比本地多出 1.2 秒以上。
7. 说「给我一本背刺附魔书和一张绿色床」→ 应分别下成两条取货请求；开关关着也应成功（本地拆句，不联网）。
8. 说「给我一本书和一张绿色床」→ 只下绿色床那一件，并提示「（还有 1 件没对上：…）」（不能猜成别的书）。
9. 仓库里只有橡木木板时，说「给我一组橡木原木」→ 应回「没找到「橡木原木」（可能仓库没有，或没听准）；最接近：橡木木板…」，**不下单**（开关开着时也只是多问一次 AI，仍不会拿木板顶替）。
10. 一句话两件、其中一件名字含糊 → 有把握的那件下单，拿不准的要么问完 AI 下对，要么明确说没听出来。
11. 面板 AI 页点「方式：…（点一下换）」循环三档，看 `settings.txt` 的 `rewrite.mode=` 是否跟着变；重进游戏保持所选。
12. 方式选「完全调用 AI 改写」，说一句本地认得出的「给我半组圆石」→ 也会问一次 AI，最终仍取 32 个；断网再说 → 提示「AI 出错，用本地」，不卡不崩。

13. 仓库里只有橡木木板，说「给我一组橡木原木」（或其它仓库没有的东西）→ 应回「没找到「…」（可能仓库没有，或没听准）…」，**不说「没听出物品名」**，不下单。
14. 开 AI 说「给我一瓶强化迟缓药水」「要三发飞行两秒的烟花」→ 下到对应属性那一行（药水时长/强化等级、烟花飞行时长不同就是不同的东西）。
15. 带口音试几句：把「石头」说成「四头」、「蓝冰」说成「南冰」、「深板岩」说成「森板岩」、
    「熔岩」说成「龙岩」→ 都应取对；反过来，仓库里只有「金剑」时说「铁剑」→ 仍应拒绝
    （口音容错不能变成乱凑）。
16. 仓库里有带等级的变体（例：不祥之瓶的「凶兆等级 III」、药箭的「药水：不祥之兆 III」）→ 只说
    「不祥之兆3」「药水箭」也应取到对应那一行、各 1 个；「不祥之兆3」的 3 当等级。反例：只有
    「凶兆等级 III」时说「不祥之兆1」→ 拒绝，不拿别的等级顶替。
17. 仓库里有两瓶不祥之瓶（凶兆等级 IV / V）时，说「不祥之兆4」→ 应取 IV 那瓶、1 个；说「不祥之兆5」→ V 那瓶；
    只说「不祥之瓶」不带等级 → 应回一句列出两种、**不下单**。

## ⬆️ 升级

覆盖 `mods/warehouse-keeper-voice-0.3.x.jar` 即可，设置与已下载模型都不用重下。**主体模组要一起
换成 `warehouse-keeper-1.2.1.jar`**（同一天重建的那份）：面板里的 API Key 输入框与三页设置页
需要这一版主体；只换语音包时，面板那几行退成只读文字，仍可去 `/warehousevoice` 填 Key。

## 已知局限

- 专用服务器上服务端语言是 `en_us` 时，索引里存进去的物品名会是英文（药水名、附魔名尤其明显）；
  这是主体模组索引层的既有问题，单人游戏与中文客户端不受影响。
- AI 服务商免费层的条款各不相同（有的明确会把内容用于改进产品），用之前请自行确认；
  不想出网就保持开关关闭或改用本地 Ollama。
- 本地 Ollama 首次调用要加载模型（`qwen3:0.6b` 约 0.5–1 GB 内存），建议在机器有余量时用。
