# Warehouse Keeper Voice v0.1.0

Warehouse Keeper 的可选语音取货附加包首个发行版。玩家按住按键说出取货需求，本附加包在本机
离线完成语音识别，将其解析为标准取货指令并交由搬运工送货。

| 项目 | 说明 |
| --- | --- |
| 适配 | Minecraft **26.3** · Fabric Loader **0.19.3+**（实测 0.19.5） · Fabric API **0.161.0+26.3** · Java **25** |
| 主体模组 | warehouse-keeper **1.1.4** 或更高（必需） |
| 运行环境 | Windows x64 |
| 文件 | `warehouse-keeper-voice-0.1.0.jar`（374,774,745 B） |
| SHA-256 | `71b53262f732baf0e2d4a43e8180d38d99342d87ea0f6dfb838afdc8dd3a9546` |
| 许可证 | MIT |

> 本附加包为纯客户端模组，服务器无需安装。未安装本附加包时，主体模组的行为不受任何影响。

## 功能

- **完全离线识别**：识别在本机 CPU 上完成，不联网，不调用任何云服务。
- **双模型并行**：同时运行 Paraformer-small 与 Zipformer-CTC-int8 两个中文识别模型；
  两条结果均参与匹配，主模型未能识别物品名时另一模型的结果自动接续。
- **面向游戏物品名的匹配**：在仓库实际持有的物品范围内闭集匹配，综合字形相似度与拼音
  （含同音与近似音）判定，支持口语化说法与数量单位（个 / 组）。
- **自动纠错记忆**：经模糊匹配或另一模型纠正成功的说法写入本机别名表，后续可直接命中；
  别名表支持手工编辑。
- **严格的库存语义**：物品不存在、数量不足或超出单次下单上限时一律不下单，并给出说明。
- **音频不落盘**：录音仅驻留内存，识别完成后立即清零，不写入任何音频文件。

## 安装

1. 安装主体模组 `warehouse-keeper`（服务端与客户端均需安装）。
2. 将本附加包放入客户端 `mods/` 目录。
3. 首次使用时随包模型与原生库会解压至 `config/warehouse-keeper-voice/`（约 450 MB），仅执行一次；
   此后每次启动均在后台预先装载模型。
4. 语音下单沿用主体模组的取货权限，需由管理员在仓库面板「权限」页授予该玩家取货权限。

## 使用

| 按键 | 功能 |
| --- | --- |
| `V`（按住） | 按住说话，松开后立即识别 |
| `B` | 切换聊天栏是否显示另一识别模型的识别结果（两个模型始终同时运行） |

完整说明见附件 `Warehouse-Keeper-Voice-0.1.0-使用说明.md`。

## 已知限制

- 当前版本仅随包提供 **Windows x64** 原生库，其他操作系统暂不支持。
- 两个语音模型常驻内存，约占用 0.5–1 GB；可在 `settings.txt` 中调整 `parallel` 与 `preload`。
- 首次使用需解压约 450 MB 的模型文件，此后不再重复解压。
- 识别结果以中文物品名为准；专用服务端在无客户端连入时输出英文物品名，但匹配在客户端完成，不受影响。
