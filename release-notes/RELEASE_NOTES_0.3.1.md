# Warehouse Keeper Voice v0.3.1

本版两件事：① **下载源从「一个前缀 + 两个选项」改成注册表 + 五个选项** —— 默认仍是官方原始源
（`huggingface.co`），但大陆玩家可以直接选 **魔搭 ModelScope**（四个模型都实测收录过，与官方逐字节
同一份），或者交给「自动」按顺序试；② **把「低频轰鸣被误报成人声太轻」这条改清楚**：同一段录音
现在能分辨「是低频噪声盖住了人声」还是「人声确实太轻」，两条路各给各的处置建议，而不是统一骂玩家
说得轻。音频处理链路本身一个字没改（没动高通、分帧、裁剪与增益），所以识别结果不会因为本版变差。

## ✨ 本次变更

- **下载源变成注册表 + 五个选项**：以前下载地址散着拼（设置页写死「官方 / hf-mirror」两个选项，
  拼地址的代码另写一套），现在收进 `VoiceMirrors` 一处，界面只轮换选项 id。设置页里那一行
  点一下换下一个，顺序是：

  | 选项 | 界面名 | 说明 |
  | --- | --- | --- |
  | `official` | HuggingFace 官方 | **默认**。原始下载源，需要能连上 `huggingface.co` |
  | `hfm` | hf-mirror | 国内可达的转发站；实测会 308 跳回官方，**不是**独立的一份源 |
  | `modelscope` | 魔搭 ModelScope | 大陆直连；四个模型都已实测收录，没有收录的模型自动回退官方 |
  | `auto` | 自动 | 按顺序试：魔搭（有镜像时）→ hf-mirror → 官方 |
  | `custom` | 自定义前缀 | 手填网址前缀，按「前缀/repo/resolve/main/文件名」拼；写进 `mirror=` |

- **每个源失败自动换下一个、已下载的部分不浪费**：候选地址是一张**有序表**，某个源下不动就自动换
  下一个（换源时保留 `.part`，续传继续），全部失败才报错并说明最后试的是哪个源。选 `modelscope`
  时，没有魔搭镜像的文件会直接退到官方，而不是去拼一个不存在的魔搭地址再拿回 404 页面。

- **魔搭 ModelScope 实测收录四个模型**（2026-10-16 复核，逐个仓库核对文件列表里的
  `Size` 与 `Sha256`，与代码里写死的值逐一相同）：

  | 模型 | 魔搭仓库 |
  | --- | --- |
  | SenseVoice | `poloniumrock/SenseVoiceSmallOnnx` |
  | Paraformer 小 | `pengzhendong/sherpa-onnx-paraformer-zh-small` |
  | Paraformer 完整版 | `pengzhendong/sherpa-onnx-paraformer-zh` |
  | Zipformer-CTC | `csukuangfj/sherpa-onnx-zipformer-ctc-zh-int8-2025-07-03`（与 HuggingFace 同名） |

  - 魔搭的仓库名与 HuggingFace **不是**同一个（SenseVoice 是 `poloniumrock/...`，两个 Paraformer 在
    `pengzhendong/` 命名空间下），所以映射表一个都不能从 HF 仓库名拼出来，全部单独写死。
  - `tokens.txt` 这类非 LFS 文件是直接 `200` 返回的：本次实测**下载后本地 sha256 与写死值逐字节相同**。
  - `model.int8.onnx`、`bbpe.model` 这类 LFS 文件走 `302` → `cdn-lfs-cn-1.modelscope.cn`，跳转地址里的
    对象路径**就是该文件的 sha256**（内容寻址，等于「同一份文件」的证明）。
  - 跳转地址里带 `auth_key` 且有时效，所以**每次都必须重新走 `resolve/master` 取跳转**，不能把 CDN
    地址缓存下来复用；下载器每次请求都是新建请求，天然满足。
  - 断点续传在魔搭上同样有效：在 367,074,356 B 的 Zipformer 上实测 `Range: bytes=0-99` 与
    `bytes=1000000-1000099` 都返回 `206` 且 `Content-Range` 正确（`bytes 0-99/367074356`、
    `bytes 1000000-1000099/367074356`），起点越界返回 `416` + `bytes */367074356`。

- **当前源在界面上看得见**：设置页那一行显示当前下载源（自定义模式连前缀一起显示），状态栏在选到
  魔搭/自动而当前模型没有镜像时补一句「魔搭没有这个模型的镜像，回退官方」；下载时进度条后面显示
  当前正在用的源（`[魔搭]` / `[官方]` / `[hf-mirror]` / 自定义时显示主机名），下载日志里写出
  「下载源：…」与「候选下载源（按顺序试）：…」两张清单，排查时不用再猜它在连哪。

- **老配置原样接过来**：设置文件新增 `mirrorMode=` 键；老文件里没有它时，按 `mirror=` 里的地址反推
  模式 —— `https://hf-mirror.com` 认成 hf-mirror、`https://huggingface.co` 认成官方、其它网址认成
  自定义前缀（与老版本「非空 mirror 当前缀拼」的行为一致）。`mirrorMode=` 写了但认不出来的值，
  记一条警告后按默认的官方走，并且**不会**静默写错。
  `mirror=` 这个键仍然保存一个「老版本也认得的地址」（`custom` 存前缀，`hfm` 存 hf-mirror，其余存
  官方），所以万一回退到 0.3.0，它读到的不是 `modelscope` 这种被当前缀拼的字符串。

## 🧩 面板里就能下载/删除模型（需要主体 warehouse-keeper 1.2.1+）

主体面板「设置 → 语音取货」这一页现在和 `/warehousevoice` 是同一套功能：

- 每个模型一行，右边一个按钮：没装=「下载」、正在下=「取消」、装好了=「删除」（删除要点两下确认）
- 上面一行「下载状态」是活的：百分比、当前第几个文件、上次为什么没下成，都写在那里
- 下载完成后不管你在哪个界面，模型都会自动装进内存（以前只有开着语音设置页才会接手）

老的 6 项开关（主/副模型、对照、并行、预加载、下载源）不变，改的还是同一份 `settings.txt`。
## 🐛 问题修复

- **低频轰鸣不再被一律说成「说得太轻」**：环境里有很响的 50/60 Hz 交流声、地环路嗡鸣或风扇低频噪声
  时，噪声底被抬高、信噪比压到门槛以下，以前统一提示「人声太轻或太远」——玩家照着提示喊也没用，
  因为真正的问题是噪声不是音量。现在在**原来的拒绝分支里**多算一个「低频占比」：把原始录音再过
  两级一阶低通（截止 **200 Hz**，级联后接近二阶），看低频能量占全带的比重，与门限 **0.60** 比较。

  - 判定只在「信噪比本来就不达标、这段录音无论如何都会被拒」的分支里参与，**只读原始采样、不改
    滤波后的音频**，所以高通、分帧、信噪比、裁剪与增益的输出与 0.3.0 完全一致（三档增益不变）。
  - 门限实测标定（2026-10-16）：被拒的低频轰鸣（30 / 50 / 60 / 100 / 120 Hz 纯音、以及轻声说话叠
    50 Hz 轰鸣）低频占比 **0.735 ~ 0.978**，被拒的宽带白噪声只有 **0.080**，而能通过的正常录音在
    **0.17 ~ 0.66** —— 0.60 取在两簇中间。
  - 两条提示现在各说各的问题：
    - 低频占大头时：「环境里的低频轰鸣/交流声太强（低频占 X%，人声 A，中位 B，环境噪声 C）——
      是低频噪声盖住了人声，不是说话太轻：离风扇、音响、变压器、电源线远一点，或关掉麦克风的
      「增强／自动增益」再试一次」
    - 确实是音量问题：「人声太轻或太远（人声 A，中位 B，环境噪声 C）——靠近麦克风、说大声点
      再说一次」

- **下载时不再依赖「别处刚好加载过设置」**：点「下载」现在先读一遍设置文件再取下载源，避免在某些
  启动顺序下拿到的还是默认值（表现为「我明明选了魔搭，它却从官方下」，而设置页看起来是对的）。

- **文档里的下载入口写错了**：README 与使用说明以前把「镜像」的默认值写成 `https://hf-mirror.com`
  （实际默认一直是官方），这一版按代码改成「默认官方、镜像可选」，并把五个选项与新键一并写清。

## ⚠️ 已知局限

- **仍然没有改音频链路**：一阶高通（约 70 Hz）对 60 Hz 交流声只衰减约 1.3 dB 这件事没变。要真正
  压掉它需要二阶/更高阶高通或频谱分离，而那会改动 `filtered[]`，连带影响峰值、噪声底、人声电平
  与三档增益的输出 —— 等于换一套前处理，风险明显大于收益，本版刻意不做。所以**环境噪声极强时这段
  录音仍会被拒**，只是现在会告诉你「是低频噪声盖住了人声」并给出可行处置，而不是让你反复喊。
- **魔搭上的模型是第三方上传的仓库**（SenseVoice 由 `poloniumrock` 上传）：有可能被删除或换文件。
  对策是保留原有的「下载后校验确切字节数与 sha256」+ 官方兜底，映射表里也逐个注明了来源与核实日期；
  魔搭从不是唯一源。
- **大陆可选的独立源目前只有魔搭一家**：另外两个候选都不成立 —— `zhaochaoqun/sherpa-onnx-asr-models`
  顶层只有整包 `.tar.bz2`（缺 SenseVoice 单文件），`xiaowangge/sherpa-onnx-sense-voice-small` 的
  `resolve/master/model.int8.onnx` 返回 404。本版没有引入新的整合源。
- `hf-mirror.com` **不是**独立备份源：实测 308 → `huggingface.co` → 302 → `us.aws.cdn.hf.co`，
  连不上 huggingface 时换它也一样下不动。它的价值只是「能连上时的国内加速」。
- **默认模型的识别率差异仍待真人复测**（研究记录里的 V-07）：本版没有换默认模型、也没有调识别参数，
  多个模型之间的准确率比较需要真实录音与真人测试，不在本版范围内。

## ⬆️ 升级提示

- 把 `mods\` 里的旧 `warehouse-keeper-voice-*.jar` 换成 `warehouse-keeper-voice-0.3.1.jar` 即可
  （不要同时留两个同名模组 ID 的 jar）。已下载的模型、`settings.txt`、`aliases.txt` 原样沿用。
- **老 `settings.txt` 行为不变**：只写了 `mirror=`（或什么都没写）的配置按上面的规则反推模式，
  原来能用官方源的现在还是官方源，原来填了自定义前缀的还是自定义前缀。游戏第一次启动时会顺手把
  `mirrorMode=` 写进设置文件（注释里列全五个可选值）。
- 想在大陆直连下载：输入 `/warehousevoice`（或主体设置页的语音附属页），把「下载源」那一行点到
  「魔搭 ModelScope」，再点「保存并应用」；想让它自己挑就点「自动」。默认值保持「HuggingFace 官方」
  不变，不会因为升级而改变任何人的下载行为。
- 主体模组仍需 1.1.4 或更高，服务端无需安装本附加包。
