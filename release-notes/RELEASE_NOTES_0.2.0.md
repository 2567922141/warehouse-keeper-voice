# Warehouse Keeper Voice v0.2.0

录音前端重写 + 别名表卫生 + 模型按需下载。本版解决「只有某一个人的声音识别得准」，并把核心模型从 jar 里拿出来改成按需下载：**jar 从 374 MB 降到 83 MB**，默认模型换成对多口音更稳的 SenseVoice，没下载时自动回退到随包内置的小模型。

## ✨ 新增

- **语音设置页**：输入 `/warehousevoice`（简写 `/wvoice`）打开，也可以从命令看状态（`/warehousevoice status`）。页面里能选主模型、副模型（主模型没听出时再问它一次）、切换「对照／并行／预加载」、切换下载镜像，改完点「保存并应用」。
- **模型按需下载**：Paraformer 小（内置，无需下载）／SenseVoice（推荐，约 228 MB）／Zipformer-CTC（约 350 MB）／Paraformer 完整版（约 217 MB）。下载走 `hf-mirror.com`（失败自动换源到官方 huggingface），支持断点续传、sha256 校验、后台进行（关掉页面不中断）、可随时取消。文件落在 `config\warehouse-keeper-voice\models\<模型id>\`，**不写世界存档目录**；联网只发生在你主动点「下载」时。
- **默认模型改为 SenseVoice**：对多口音、方言与轻声更稳。还没下载时自动先用随包内置的 Paraformer 小模型识别，并在动作栏提示「输入 /warehousevoice 打开语音设置页即可下载」。
- **别名只记物品名**：以前把「十个金币」整句记下，说「五个金币」就不认；现在只记「金币」，数量每次从话里现算（含「一组」的堆叠语义）。
- **老模型目录自动认领**：之前用 0.1.x 解压过的模型目录会被直接识别为「已就绪」，升级后不会重复下载。

## 🐛 问题修复

- **只认某个人的声音（本版重点）**：旧版拿**整段录音的最大电平**去归一化，而且增益上限只有 8 倍 —— 声音够大的人刚好被推到合适大小，说得轻或离得远的人只能以原始音量送进模型（而且底噪被一起放大）。现在改成：70 Hz 一阶高通先滤掉低频轰鸣 → 按 20 毫秒帧计算电平、取第 95／第 10 百分位分别当作**人声电平**与**环境噪声底** → 只有在人声明显高于噪声底（≥2 倍）时才按人声电平放大（上限 64 倍、并预留峰值余量）。
  离线实测：同样一句话录成幅度 170／250／2000 三档，归一化后的电平差 **0.00 dB**（旧版差约 **21 dB**）。
- **「没收到声音」不再看固定数值**：旧版整段最大电平低于 300 就报「没收到声音」，说得轻的人会被当成没说话。现在按噪声底与峰值相对判断，轻声能正常识别；真的静音或只有电流声时提示仍保留（并给出可操作的原因）。
- **拦住不是人话的输入**：静音、低频轰鸣、持续纯音、只有 50 毫秒的误触都会在录音结束时就给出中文原因（「没收到声音」「人声太轻或太远」「录到的声音太短」），不会再送进模型乱猜。
- **别名表卫生**：口水词或裸量词（「给」「给我」「一根」）不再写入别名表；勉强够线的模糊匹配不再被永久记成别名。启动时会自动剔除历史遗留的这类键，并把原文件备份为 `aliases.txt.bak`（只备份一次，之后正常写回）。
- **匹配放宽一点**：拼音相似度门槛 0.60 → 0.55，「身板」→深板岩、「不想之品」→不祥之瓶 这类真实误听能救回；**直接下单所需的分数没有降低**，选物品仍按得分与差距双重判定。
- **jar 体积**：不再随包 350 MB 的 Zipformer-CTC 模型（374,777,205 B → 82,892,135 B），下载脚本 `fetch-libs.ps1` 也只需约 90 MB。

## ⚠️ 已知局限

- 环境里有**很响的 50/60 Hz 交流声／地环路嗡鸣**时，说话可能被误报「人声太轻或太远」：一阶高通在 60 Hz 只衰减约 1.3 dB，噪声底被抬高后信噪比可能压到 2 倍以下。真修需要更高阶的高通或频谱分离，本版未做；遇到时换一副麦克风或关掉增益增强即可。
- 内置的 Paraformer 小模型对**口音、方言、轻声**的能力弱于 SenseVoice，长期使用建议在设置页下载 SenseVoice。
- 只有 transducer 类模型支持「热词表」，Paraformer／Zipformer-CTC 都不支持，所以本版没有做「把物品名当热词」这条路。

## ⬆️ 升级提示

- 把 `mods\` 里的 `warehouse-keeper-voice-0.1.0.jar`（或 0.1.1）换成 `warehouse-keeper-voice-0.2.0.jar` 即可；`config\warehouse-keeper-voice\` 下的设置与别名表原样沿用（旧设置项写法仍然认：`paraformer`→`paraformer-small`、`zipformer`→`zipformer-ctc`）。
- 进游戏后输入 `/warehousevoice` 打开设置页：想用 SenseVoice 就点那一行的「下载」（约 228 MB，走镜像），下载完成后自动可用；不下载就一直用内置的小模型，功能不受影响。
- 主体模组需 1.1.4 或更高；服务端无需安装本附加包。
